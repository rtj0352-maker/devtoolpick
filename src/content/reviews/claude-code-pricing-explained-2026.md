Claude Code isn't sold on its own: it comes **with a paid Claude plan**, or you can run it on **pay-as-you-go API credits** through a Console account. This page explains each option and when to move up.

> Figures checked on Anthropic's official [pricing page](https://claude.com/pricing) and [Claude Code page](https://claude.com/product/claude-code) on **October 21, 2026 (JST)**. Prices exclude tax and may change at Anthropic's discretion.

## Plans that include Claude Code

| Plan | Price | Claude Code | Notes |
| --- | --- | --- | --- |
| Free | $0 | No | Chat only |
| **Pro** | **$20/mo** monthly · **$17/mo** annual ($200 up front) | Yes | At least 5× Free usage per 5-hour session |
| **Max 5x** | **$100/mo** | Yes | 5× Pro usage; $100/mo in API credits; billed monthly |
| **Max 20x** | **$200/mo** | Yes | 20× Pro usage; $200/mo in API credits; billed monthly |
| Team | See Anthropic | Yes | For 2–150 people; monthly or annual |
| Enterprise | $20/seat/mo + usage at API rates | Yes | Billed annually |

## How the limits work

- **Rolling five-hour sessions**, plus **weekly limits** on paid plans.
- **One shared pool**: Claude on web, desktop, mobile and Claude Code all draw from it.
- **No fixed message count**: usage depends on conversation length, the model you pick and the features you use.
- **When you hit a limit**: wait for the reset, upgrade, or (on paid plans) turn on **usage credits** billed at standard API rates.

## Pro vs Max: when to upgrade

| You… | Plan |
| --- | --- |
| Use Claude Code a few times a week for focused tasks | **Pro** (consider annual for $17/mo) |
| Hit session limits most working days | **Max 5x** ($100) |
| Run agents for much of the day | **Max 20x** ($200) |
| Have spiky, unpredictable usage | Pro + **usage credits**, or **API credits** via Console |

A simple test: stay on Pro for a normal week of real work. If you hit limits before Friday, Max 5x is likely worth it; if you rarely do, it isn't.
