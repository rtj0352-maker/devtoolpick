You can get real AI help writing code without paying anything in 2026. But every free tier has a different catch. This guide lists what each one actually includes, checked against the vendors' own pages, so you can stack them sensibly.

> Free-tier details were checked on **October 21, 2026 (JST)** on [GitHub Copilot plans](https://github.com/features/copilot/plans), [Google Antigravity pricing](https://antigravity.google/pricing/) and [plans docs](https://antigravity.google/docs/plans/), [Cursor pricing](https://cursor.com/pricing), [CodeRabbit pricing](https://www.coderabbit.ai/pricing) and [Greptile pricing](https://www.greptile.com/pricing). Free limits change frequently.

## At a glance

| Tool | What's free | Main catch |
| --- | --- | --- |
| **GitHub Copilot Free** | 2,000 completions and 50 chat requests per month; CLI and agent mode supported | Small chat allowance; individual-plan data may be used for training unless you opt out |
| **Google Antigravity (Individuals)** | $0: unlimited Tab completions and Command requests, agent access with a weekly quota | Agent quota refreshes weekly; more needs a Google AI Pro/Ultra plan |
| **Cursor Free** | Limited agent and chat requests | Bugbot, cloud agents and third-party models need Premium ($30/mo) |
| **Greptile Starter** | AI PR review: 1 active developer, 50 credits/mo, unlimited repos | One developer only |
| **CodeRabbit (public repos)** | AI PR review on public repositories | Private repos need a paid plan |

## 1) GitHub Copilot Free: best all-round free start

Copilot Free works in VS Code, JetBrains IDEs, Visual Studio, Xcode, Neovim and more. It gives you **2,000 code completions and 50 chat requests a month**, plus agent mode and the Copilot CLI. If you outgrow it, **Copilot Pro is $10/month**.

One thing to know: GitHub says it may use interactions from Free, Pro and Pro+ users to train models unless you opt out at `github.com/settings/copilot/features`. Opting out doesn't affect your access. See [GitHub Copilot Pricing Explained](/devtoolpick/reviews/github-copilot-pricing-explained-2026/) for the paid tiers.

## 2) Google Antigravity: most generous free autocomplete

For individual (unpaid) users, Google replaced the Gemini CLI and Gemini Code Assist IDE extensions with **Antigravity CLI and Antigravity** on June 18, 2026. The individual tier is **$0/month** with **unlimited Tab completions and Command requests**, Gemini models (including Gemini 3.8 Flash) as the agent model, and access to product features like scheduled tasks and the CLI. The agent quota refreshes **weekly**.

Higher limits come from Google AI plans: Google lists AI Pro at $20/month and Ultra at $100 or $200/month, with quotas that refresh every five hours up to a weekly cap.

**Best for:** people who mostly want fast completions and an occasional agent task.

## 3) Cursor Free: try the AI-native editor

Cursor is now sold as part of The X Subscription. The **Free** tier includes limited agent and chat requests, so you can see whether the editor workflow suits you. Plus is $8/month (Grok models only), and **Premium is $30/month**, which adds cloud agents, Bugbot code reviews and third-party models at API list price. Our [Cursor vs Copilot comparison](/devtoolpick/reviews/cursor-vs-copilot-vs-devin-desktop-vs-claude-code/) explains when Cursor is worth paying for.

## 4) Free AI code review: Greptile and CodeRabbit

Writing code is half the job. Getting it reviewed is the other half:

- **Greptile Starter** is free for one active developer, with 50 credits a month (a base review costs 1 credit) and unlimited repositories, including private ones.
- **CodeRabbit** is free forever on public repositories. Install it on a GitHub or GitLab public repo and reviews start.

The full comparison is in [Best AI Code Review Tools (2026)](/devtoolpick/reviews/best-ai-code-review-tools-2026/).

## A $0 stack that actually works

1. **Editor:** Copilot Free or Antigravity for completions and chat.
2. **Review:** Greptile Starter on private repos, CodeRabbit on open-source repos.
3. **Upgrade trigger:** when you hit the monthly or weekly limit several times a month, a $10 Copilot Pro plan is usually the cheapest step up. For heavier agent work, see [Best AI Coding Tools for Solo Developers on a Budget](/devtoolpick/reviews/best-ai-coding-tools-for-solo-developers-budget/).
